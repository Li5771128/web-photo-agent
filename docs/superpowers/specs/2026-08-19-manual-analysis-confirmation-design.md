# 上传后手动确认分析设计

日期：2026-08-19

## 目标

保留 A/B 选择后各自自动上传的交互，但取消“两张图片确认后自动分析”。两张图片上传并经服务器确认后，页面显示“确认分析”按钮；只有用户点击后，任务才进入 Redis/Worker 图片内容理解流程。

如果目标图 B 是 RAW，系统必须在允许确认分析前生成并展示无 EXIF JPEG 预览，使用户能够先核对所选图片。RAW 预览生成不是 AI 分析，不改变任务的 `collecting` 状态。

## 用户体验

- A、B 继续独立自动上传，上传进度、错误和单侧替换行为不变。
- 单张上传完成后只显示“上传成功”，不会触发分析。
- A、B 均确认后显示“确认分析”操作区。
- 普通图片无需服务端预览，双侧确认后按钮立即可用。
- B 为 RAW 时，上传完成后显示“RAW 预览生成中”；预览返回前按钮保持禁用。
- RAW 预览成功后替换占位内容，按钮变为可用。
- 用户点击“确认分析”后按钮立即禁用并显示“正在提交”，成功后进入现有排队、图片内容理解和完成状态。
- 提交失败时保留图片和缩略图，显示明确错误并允许重试，无需重新上传。
- 分析尚未确认时更换 A 或 B 直接替换当前任务对应资产，不弹出取消分析提示；分析已确认后继续沿用现有“取消旧任务并创建替代任务”流程。

## API 与状态流转

### 上传确认

单侧上传接口只负责校验、存储和确认对应槽位。即使两个槽位均为 `confirmed`，任务也保持 `collecting`，且不得发送分析作业。

任务是否可以确认分析由以下条件共同决定：

- 任务属于当前匿名会话且未过期；
- 任务状态为 `collecting`，或为可重试的 `queue_failed`；
- reference 和 target 两个槽位均为 `confirmed`；
- 所有需要服务端预览的资产均已生成预览；当前仅 RAW 目标图需要该条件。

### 确认分析

新增 `POST /api/tasks/{taskId}/analysis`：

1. 在数据库事务中锁定任务和两个上传槽位并验证上述条件。
2. 使用条件更新将任务原子地从 `collecting` 或 `queue_failed` 改为 `queued`。
3. 只有取得该状态转换的请求可以发送 Redis 分析作业，防止双击或并发请求重复入队。
4. 如果任务已经是 `queued`、`recognizing` 或 `vision_ready`，返回当前状态而不重复入队。
5. Redis 入队失败时将状态改为 `queue_failed`，保留资产和预览，允许用户再次确认。

### RAW 预览作业

RAW 上传确认后发送独立的预览作业。它复用现有 Redis 队列与 Python Worker，但通过显式作业类型与完整分析作业区分：

- `prepare_preview`：只读取指定 RAW 对象、生成安全 JPEG 预览并更新资产，不调用千问。
- `analyze`：执行现有 A/B 预览准备和千问图片内容理解。

预览作业携带任务 ID、角色和对象键。Worker 写回时必须同时验证任务仍可用、角色资产仍指向同一对象键；用户在预览生成期间换图后，旧作业的迟到结果必须被丢弃并清理。

分析作业继续具备预览生成兜底能力，但 API 只有在所需 RAW 预览已就绪时才允许入队，因此正常交互不会依赖该兜底。

## 前端状态

任务快照增加可直接推导或显式返回的分析就绪信息。前端在 `collecting` 状态下，如果已有 RAW 资产但预览尚未就绪，则每 3 秒轮询任务快照；普通双图无需额外轮询。

“确认分析”操作区区分四种状态：

- 等待另一张图片：不显示按钮；
- RAW 预览生成中：显示禁用按钮及状态说明；
- 可以分析：显示可点击的“确认分析”；
- 正在提交或已开始：按钮禁用，随后由现有任务状态展示接管。

前端按钮状态只是交互保护，服务端仍独立校验全部前置条件。

## 错误与并发处理

- RAW 预览解码失败时，目标图槽位进入可恢复错误状态并提示用户更换 B；不能允许确认分析。
- 预览队列暂时不可用时保留已上传 RAW，显示预览准备失败并允许重试，不将其误报为 AI 分析失败。
- 同一任务的重复确认请求最多产生一个分析作业。
- 确认分析与换图并发时，数据库锁和状态条件保证只有一个操作取得有效状态；失败一方返回可理解的冲突提示。
- 取消、替换或过期任务的预览结果和分析结果均不得写回有效状态。

## 验收与验证责任

- A/B 均确认后任务仍为 `collecting`，Redis 中没有分析作业。
- 页面显示“确认分析”按钮，点击前不调用千问。
- 普通图片对点击按钮后只入队一次。
- RAW 上传后先生成并展示安全预览，预览就绪前不能确认分析。
- RAW 预览生成不调用千问，也不把任务改为 `recognizing`。
- 确认失败可以重试且不要求重新上传。
- 确认前单侧换图不触发“取消分析”提示，旧 RAW 预览不能覆盖新图。
- 确认后的换图和重新开始继续遵守现有取消安全约束。

用户已明确本次实现完成后由其自行手动验证。实施对话不运行自动化测试或构建，交付时必须明确标注代码未经自动验证，不得声称测试通过。

## 范围外

- 确定性图像测量和 Lightroom 参数计划；这些继续属于 Issue 02。
- 修改 A/B 自动上传、上传进度、格式和大小限制。
- 为 AI 图片内容理解提供百分比。
- 新建独立 RAW 预览微服务或在浏览器本地解码 RAW。

# Design directory font-size adjustment

## Scope

Increase every explicit CSS font size in `design/app.css` and the three HTML files in `design/` by 2px. This includes `font-size` declarations, `font` shorthand declarations, responsive overrides, markup styles, and styles created by JavaScript.

## Non-goals

Do not alter font family, line height, spacing, dimensions, colors, or interaction behavior.

## Verification

Check the resulting declarations to ensure every pre-existing pixel-based font size increased by exactly 2px and that the edited HTML remains structurally valid.

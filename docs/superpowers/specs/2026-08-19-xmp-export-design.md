# 可选 XMP 预设导出设计

Status: approved

## 目标

用户可在分析任务已经生成并保存安全 Lightroom 参数计划后，主动下载一个确定性生成的 XMP 预设。该文件只是手动调色的起始配方；导出失败不得改变任务状态、隐藏结果或阻塞参数卡。

首版兼容当前受 Adobe 支持的 Lightroom Classic 14/15，不为已停止支持的旧 Process Version 增加降级映射。

## 方案

采用请求时同步生成并直接下载。XMP 是很小的纯文本文件，不需要模型、图像计算或长时间处理，因此不进入 Redis/Worker，不写入 PostgreSQL，也不暂存 MinIO。这样避免为一次性匿名任务增加导出状态、对象生命周期和额外清理责任。

服务端提供会话受保护的任务级导出接口。接口必须同时确认：

- 任务属于当前匿名会话；
- 任务尚未过期；
- 数据库中存在已校验的 `safe_plan`。

生成模块只接受安全计划及稳定的预设标识上下文，不读取模型草案或自由文本来推导参数。相同任务和安全计划必须生成相同内容。

## 参数映射

允许写入以下已校验全局参数：

- 基础明暗：曝光、对比度、高光、阴影、白色色阶、黑色色阶；
- 全局效果：纹理、清晰度、去朦胧、暗角；
- 全局色彩：自然饱和度、饱和度；
- 颜色混合：现有红、橙、蓝饱和度和橙、蓝明亮度。

不写入以下内容：

- 白平衡、色温和色调；
- 曲线；
- 只有平衡值、没有色相和饱和度配方的孤立颜色分级平衡；
- 裁切、镜头校正、蒙版、修复及其他照片专属设置；
- 未在白名单中的未知参数；
- 模型说明文字中提及、但安全计划没有结构化表达的调整。

Lightroom Classic 人工验证表明，独立 XMP 预设中的相对白平衡字段可能把小偏移夹到绝对上限。生成器因此完全省略白平衡、色温和色调，保留照片应用预设前的白平衡；用户按照参数卡手动输入这两项。生成器同时负责 XML 转义、固定字段顺序、稳定 UUID 和安全文件名。

## 用户界面

Lightroom 参数计划区增加次级“导出 XMP”按钮。按钮只在安全计划存在时显示；旁边持续展示提示：XMP 不修改白平衡，色温和色调需按参数卡手动输入，应用后仍可能需要小范围微调。

点击后由浏览器请求导出接口并将成功响应保存为 `.xmp`。导出期间只禁用导出按钮。失败时在按钮附近显示可理解的错误，不清空或折叠参数卡，不改变分析任务的 `ready` 状态。

## 错误处理与安全

- 无有效会话、任务不属于会话或任务已过期时，按现有任务接口返回不存在。
- 没有安全计划时返回冲突错误，不能退回使用模型草案。
- 安全计划包含无法识别的数据时，生成器拒绝导出，而不是静默生成不可信文件。
- 白名单明确排除的、已知但不支持导出的安全参数可以省略；至少一个参数成功映射后才生成文件。
- XML 中的名称和文本经过转义；响应使用 XMP MIME、附件下载头和禁止缓存头。

## 验证

- 单元测试证明相同输入产生相同 XMP、固定字段顺序和稳定 UUID。
- 覆盖所有允许参数到 Camera Raw XMP 字段的映射，并证明白平衡、色温和色调字段不会进入文件。
- 验证曲线、孤立颜色分级平衡和照片专属设置不会进入文件。
- 验证特殊字符被正确转义，未知结构和空映射会拒绝导出。
- 验证只有当前匿名会话的未过期任务及其安全计划可以下载。
- 验证导出错误不会影响现有参数卡，并运行 Web 测试、TypeScript 检查和生产构建。

## 架构影响

`ARCHITECTURE.md` 中将 XMP 描述为对象存储临时资产及异步 `exporting` 状态，与本设计的轻量同步下载不一致。实现时同步更新架构文档：XMP 仍是已校验计划的次级分支，但不持久化、不进入任务状态机，也不增加清理对象。

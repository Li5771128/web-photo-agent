# 04 — 同会话二次微调与临时数据清理

**What to build:** 用户可在当前临时任务中上传按照建议调整后的 JPG 预览图，获得基于上一轮计划的新一轮受约束微调建议。任务处理完成或会话过期时，系统清理原始上传文件和可识别 EXIF，同时不创建持久化偏好或历史记录。

**Blocked by:** 02 — 参考风格报告与安全 Lightroom 参数计划。

**Status:** ready-for-agent

- [ ] 用户可在同一临时会话上传调整后的 JPG 预览图发起新一轮分析。
- [ ] 新一轮建议使用上一份已校验参数计划和新预览图的测量结果，并继续提供范围、理由、效果和风险。
- [ ] 微调不创建账户、偏好档案、跨任务个性化或长期任务历史。
- [ ] 处理完成或会话过期后，系统删除原始上传文件和可识别 EXIF；清理失败不会被伪装为已完成。

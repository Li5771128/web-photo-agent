# 03 — 可选 XMP 预设导出

**What to build:** 用户可从已校验的 Lightroom 参数计划中主动选择下载 XMP 预设，作为手动调色的起始配方。该可选出口不改变核心参数卡路径，也不会因导出失败而阻塞用户继续手动调整。

**Blocked by:** 02 — 参考风格报告与安全 Lightroom 参数计划。

**Status:** ready-for-human

**Archive:** completed — 5/5 项已实现，Lightroom Classic 初步导入验证通过。

- [x] 只有存在已校验参数计划时，用户才能主动触发 XMP 导出。
- [x] XMP 由确定性逻辑根据已展示的结构化参数生成，不由模型直接编写文件内容。
- [x] 导出仅包含适用的全局调色项：基础明暗、颜色混合、色彩分级和全局效果；不包含白平衡、曲线、裁切、镜头校正、蒙版或修复。
- [x] 下载前明确说明 XMP 是起始配方，仍可能需要小范围手动微调。
- [x] 导出失败时保留完整参数卡和可理解的错误提示。

## Comments

### 2026-08-18 — 未开始

当前没有已校验 Lightroom 参数计划，因此 XMP 分支尚不具备合法输入。本 issue 的五项验收均未开始，继续被 issue 02 阻塞。

### 2026-08-19 — 兼容范围与曲线调整

- 首版导出以当前受支持的 Lightroom Classic 14/15 为兼容目标，不为已停止支持的旧 Process Version 增加降级映射。
- 当前不需要导出曲线；曲线从 XMP 导出范围中删除，且生成器不得根据模型说明或图像测量自行推导曲线。
- 只有能从已校验结构化计划可靠映射的参数才写入 XMP；无法形成有效配方的孤立颜色分级平衡不写入文件。

### 2026-08-19 — 当前实现

- 新增会话受保护的 `GET /api/tasks/:taskId/xmp`；仅 `ready` 且存在 `safe_plan` 的未过期任务可以导出。
- XMP 在 Web 进程内按请求确定性生成并直接下载，不进入模型、队列、数据库或对象存储，也不改变任务状态。
- 生成器按固定白名单映射基础明暗、全局色彩、颜色混合和全局效果；明确省略白平衡、曲线、孤立颜色分级平衡及照片专属设置。
- 色温和色调继续显示在参数卡中，由用户在 Lightroom 手动输入。
- 结果页增加导出按钮、起始配方提示和局部错误状态；导出失败不会清除或阻塞参数卡。
- 10 项 Web 测试和 Next.js 生产构建通过；修复后的 Lightroom Classic 14/15 实际导入效果留待人工复验。

### 2026-08-19 — 白平衡极值缺陷修复

- 人工导入证明 `WhiteBalance="Custom"` 配合 `IncrementalTemperature` / `IncrementalTint` 会把小偏移错误夹到 `50000 / +150`。
- 数据库中的近期安全计划只有 `+8`、`+11.7` 等小色温偏移和 `-5`、`+5` 等小色调偏移，排除模型或校验器产生极值。
- XMP 生成器不再写入任何白平衡、色温或色调字段，从而保留照片应用预设前的白平衡；参数卡仍提供这两项供手动输入。
- 新增针对极值症状的回归测试，修复前失败、修复后通过。

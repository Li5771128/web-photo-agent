# 03 — 可选 XMP 预设导出

**What to build:** 用户可从已校验的 Lightroom 参数计划中主动选择下载 XMP 预设，作为手动调色的起始配方。该可选出口不改变核心参数卡路径，也不会因导出失败而阻塞用户继续手动调整。

**Blocked by:** 02 — 参考风格报告与安全 Lightroom 参数计划。

**Status:** ready-for-agent

**Archive:** pending — 0/5 项完成。

- [ ] 只有存在已校验参数计划时，用户才能主动触发 XMP 导出。
- [ ] XMP 由确定性逻辑根据已展示的结构化参数生成，不由模型直接编写文件内容。
- [ ] 导出仅包含适用的全局调色项：基础明暗、白平衡、颜色混合、色彩分级和全局效果；不包含曲线、裁切、镜头校正、蒙版或修复。
- [ ] 下载前明确说明 XMP 是起始配方，仍可能需要小范围手动微调。
- [ ] 导出失败时保留完整参数卡和可理解的错误提示。

### 2026-08-19 — 兼容范围与曲线调整

- 首版导出以当前受支持的 Lightroom Classic 14/15 为兼容目标，不为已停止支持的旧 Process Version 增加降级映射。
- 当前不需要导出曲线；曲线从 XMP 导出范围中删除，且生成器不得根据模型说明或图像测量自行推导曲线。
- 只有能从已校验结构化计划可靠映射的参数才写入 XMP；无法形成有效配方的孤立颜色分级平衡不写入文件。

# 02 — 参考风格报告与安全 Lightroom 参数计划

**What to build:** 对已上传的有效 A/B 图片对，用户可获得参考图风格报告、A/B 匹配可行度和可手动执行的 Lightroom 参数计划。计划按基础校正、风格塑形、可选微调排序，并以受校验的参数卡展示建议、解释与风险。

**Blocked by:** 01 — 匿名 A/B 调色任务与上传校验。

**Status:** ready-for-agent

- [ ] 报告展示参考图的风格摘要、主色/色彩倾向、明暗分布、对比度与饱和度，并区分可迁移与不可迁移特征。
- [ ] 输出 A/B 匹配可行度和限制说明；素材不匹配时不伪装为可精确复刻。
- [ ] 每张参数卡包含 Lightroom 面板、参数、推荐值或范围、理由、预期效果和风险，并按既定编辑顺序展示。
- [ ] 参数在展示前经过格式相关的安全校验；面对裁切、肤色风险或 JPEG 等有限调整空间时收紧建议或解释限制。
- [ ] RAW 可使用可用的 EXIF 与动态范围线索；其他已输出图片不假设存在可恢复的原始数据。
